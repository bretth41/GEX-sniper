UNIVERSAL FRAMEWORK — Time Windows & Bar Rules

Core Design Principle

Every bar-based signal declares its time window explicitly before computing. No signal uses an undeclared or implicit lookback. All signals use rolling timestamp filters on 1-minute OHLC bars (raw1m), never fixed bar counts. Intent is always self-documenting in the code.

The Two Universal Window Constants

ConstantValueUsed ByPurpose
WIN_SIGNAL_MS10 minutesWX, RQ candles, EMA8 coilSetup formation — matches 2-10 min trade duration
WIN_CONTEXT_MS30 minutesRQ drift, G1 intraday blendStructural backdrop — detects grinds and session accumulation

Universal Filter Pattern

// Declared at top of every compute function that uses bars const nowMs = Date.now(); const bars = raw1m.filter(b => (nowMs - b.t * 1000) <= WIN_SIGNAL_MS); // Never use raw1m.slice(-N) — always declare window before computing

Bar Definition Rule

A "bar" is always a 1-minute OHLC bar from raw1m. Timestamps (b.t) are Unix seconds from the UW API. Convert to ms: (nowMs - b.t * 1000). Going forward, every new signal or modification must declare its window constant before use — never embed a bar count as a magic number.

G1 — GEX Dealer Delta (Tide + Current) Structural dealer positioning with time-decay weighting

Data Sourcegreek-exposure/strike (tide) · greek-exposure/expiry (current) · flow-alerts (volume) WindowTide: session-wide API · Current: WIN_CONTEXT_MS flow count · Volume: session accumulation

Formula / Computation

// Session time decay (9:30am open → 4:00pm close) sessionPct = min(1, max(0, (etHour() - 9.5) / 6.5)) tideFactor = 0.90 - sessionPct × 0.60 // 0.90 at open → 0.30 at close currentFactor = 1.10 + sessionPct × 0.60 // 1.10 at open → 1.70 at close // Weights always sum to 2.0 // TIDE: structural dealer delta (all expirations) structNorm = clamp(-netDealerDelta / g1StructuralMax, -1, 1) // CURRENT: 0DTE+1DTE intraday delta (active hedging today) currentBlend = intradayNorm × oiW + volNorm × volW // FINAL: (tide × tideFactor + current × currentFactor) / 2 + EMA context 10% g1Score = clamp((tideContrib + currentContrib)/2 × 0.90 + emaScore × 0.10) × 2

  • Composite weight: g1Score × 0.40 (largest single contributor).

F1 — Flow Intelligence (Opening vs Closing) VOI-decomposed sweep accumulation

Data Sourceflow-alerts (UW) — sweep classification with VOI + OI confirmation Window60-min rolling sweeps · 15-min net premium · oiDeltaHist (last 4 readings × 30s)

Formula / Computation

// Per-sweep: two multiplicative factors applied before scoring voiFactor = voi < 3x ? 1.0 : voi < 8x ? 0.5 : 0.1 // <3x=opening, >8x=closing oiConfirm = confirming ? 1.2 : neutral ? 1.0 : opposing ? 0.3 sweepScore = dteFactor × sizeFactor × recency × voiFactor × oiConfirm // Accumulation with cluster bonus (≥2 sweeps same expiry = 1.2×) f1SweepAccum.score = min(2.0, sum(alignedSweeps.score) × clusterBonus) // Net premium layer (15-min window, secondary) premScore = clamp((callNet - |putNet|) / totalPrem, -1, 1) f1Score = sweepScore × 0.85 + premScore × 0.30 (capped at 2.0)

Scoring Details

  • DTE factor: 0DTE=0.90, 1-7DTE=1.00 (peak), >90DTE=0.10.
  • Size factor: <$100K=0.25, <$500K=0.50, <$2M=0.75, <$5M=0.90, ≥$5M=1.00.
  • voiFactor hammers closing flow: >8x VOI scores only 10% of full weight.
  • oiConfirm uses oiDeltaHist slope: opposing OI reduces weight to 30%.
  • Direction-sensitive freshness: sigFreshSweepTs only updates from sweeps matching signal direction. Call sweeps during STRONG_PUT do NOT reset the stale clock.
  • Refire guard: sigHasBeenNeutral must be true before re-qualifying for STRONG.

Composite Contribution

  • trigCall/trigPut: f1Strength ≥ 1 (required for CALL/PUT state).
  • swCall/swPut: f1Strength ≥ 2 (required for STRONG state).
  • f1ConvFactor: 0.70 + (sweepScore/2.0) × 0.30 — scales composite amplitude.
  • freshFactor: 1.0 at <5 min, decays to 0.10 at 60 min — penalizes stale signals.
  • Composite weight: f1Score × 0.35.

RQ — Regime Quality Classifies: TRENDING / RANGING / STRESS / NEUTRAL

Data Sourceraw1m (1-min OHLC) · vixPrice · oiDeltaHist · ema8Val WindowCandles + EMA8: WIN_SIGNAL_MS (10 min) · Drift: WIN_CONTEXT_MS (30 min)

Formula / Computation

// Candle classification — WIN_SIGNAL_MS rolling (10 min) srcBars = raw1m.filter(b => (nowMs - b.t*1000) <= WIN_SIGNAL_MS) body = |close - open| / range wickBias = lowerWick - upperWick // positive=bullish, negative=bearish // EMA8 rejection count (same srcBars window) ema8RejectBear: wick >= EMA8 AND close < EMA8 // seller defended EMA coilBear = rejectBear >= 3 AND persistBear >= 50% of window bars // Directional drift — WIN_CONTEXT_MS rolling (30 min) driftBars = raw1m.filter(b => (nowMs - b.t*1000) <= WIN_CONTEXT_MS) driftScore = clamp(priceChange / (atr × barCount), -1, 1) hasDrift = |driftScore| > 0.35 // RvI: realized vs implied volatility ratio realizedVsImplied = atrVal / perBarImplied // >0.85 = trending environment

States

StateConditionsrqScoreComposite Effect
TRENDINGbodyTrend OR drift OR coil, AND RvI > 0.85±0.10 to ±0.22Composite amplified. Trade with conviction — follow signal direction.
RANGINGNot trending, RvI < 0.80 or body declining-0.10Composite dampened. Reduce size. Grind day — use WX for precision entries.

Scoring

  • TRENDING: dirSource × 0.15 × coilAmp × oiMod, clamped to ±0.22.
  • coilAmp = 1 + min(coilCount/8, 0.5) — more EMA8 rejections = stronger amplification.
  • oiMod: strengthening OI = 1.20, weakening OI = 0.80, neutral = 1.00.

Composite Contribution

  • rqMult applied to composite: TRENDING=1.15, RANGING=0.85.
  • rqNotOpposing gate: STRONG requires RQ not contradicting signal direction.
  • RQ does not block CALL/PUT states — only affects the STRONG gate (condition 3 of 5).
  • Composite weight: rqScore × 0.25.

▸ RQ answers "what regime is this?" — NOT the same question as WX. WX detects a specific price exhaustion. RQ classifies the broader environment. On grind days, RANGING shows all day while WX catches specific setup windows.

Decay & Guards

  • Stale poll count: STRONG downgrades to CALL/PUT after 2 polls (~10s) without fresh direction-matching sweeps.
  • Price invalidation: >0.35% move against direction resets to NEUTRAL.
  • 2-minute lock: after firing, signal locks direction for 120 seconds.
  • 8-minute refire guard: requires swCall/swPut (score ≥ 2) to refire within 8 minutes.
  • Confirmation: 2 consecutive poll cycles must agree before state change.
